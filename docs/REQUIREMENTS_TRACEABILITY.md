| 旧数据安全升级 | 文件锁内幂等 SQLite migration | 旧 schema 双线程迁移测试 |

## Definition of Done

只有同时满足以下条件才算完成：

1. 无第三方依赖即可启动；
2. 自动测试全部通过；
3. HTTP 健康检查真实返回 200；
4. 浏览器中完成提交并看到批改结果；
5. Git 工作树清晰，关键阶段有提交；
6. README 包含启动、调度、备份与恢复步骤。
