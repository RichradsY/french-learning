# Système d’apprentissage du français — 系统设计

## 1. 产品目标

为 TCF B1 学习者提供一个本地、低干扰、可追踪的每日训练系统。每天自动准备：

- 5 道法语选择题；
- 5 道同主题/同难度但不重复的法语填空题；
- 每题提交后或整套提交后可批改；
- 所有选项均有中法双语解释；
- 10 个词汇：5 个带“社区/时事语境”来源标签的新词，5 个日常高频词；
- 词汇与例句可调用浏览器法语语音朗读；
- 可查看历史、错题、语法点与学习统计；
- 每天 07:00 自动生成当日内容。

题干、选项、输入提示保持纯法语；中文只出现在提交后的解释、语法说明和批改反馈中。

## 2. 范围与边界

### 本版必须完成

1. 本地 Web 应用，仅绑定 `127.0.0.1`。
2. SQLite 持久化，无云端账号。
3. 每日内容生成与跨日去重。
4. 批改、得分、答案与完整选项解释。
5. 历史、错题、语法点、词汇页。
6. Web Speech API 法语发音。
7. 内置调度器 + macOS LaunchAgent（07:00 唤醒运行）。
8. 自动测试与 Git 版本管理。

### 有意延后

- 在线账户和多设备同步；
- 自动抓取任意社交平台（易受 API、版权与内容质量限制）；
- 无审核的 LLM 自动出题。

社区词汇采用“可追溯语境池”：每个条目记录法语来源名称、URL、摘录日期及改写后的 B1 例句。核心应用不依赖网络；后续可替换为 RSS/LLM 审核管线。

## 3. 架构

```text
Browser (HTML/CSS/JS)
  ├─ 今日训练 / 即时交互 / SpeechSynthesis
  ├─ 历史、错题、语法、词汇
  └─ fetch JSON API
          │ 127.0.0.1:8765
Python HTTP Server
  ├─ Router/API validation
  ├─ LearningService（业务规则）
  ├─ DailyContentGenerator（模板、抽样、去重）
  └─ SQLiteRepository（事务、查询、统计）
          │
      learning.db

Scheduler
  ├─ 应用进程内：跨过 07:00 后补生成
  └─ macOS LaunchAgent：每天 07:00 执行 generate-today
```

### 设计原则

- **离线优先**：无 API key 也完整工作。
- **分层**：HTTP、业务、生成、存储互不耦合。
- **幂等**：同一天重复生成不会产生第二套内容。
- **可恢复**：数据库事务写入；提交答案可重复读取。
- **教学约束可测试**：题量、语言边界、选项解释、去重均进入测试。
- **渐进披露**：答题前不显示答案；提交后再展开解释。

## 4. 数据模型

### `daily_sessions`

| 字段 | 说明 |
|---|---|
| id | 主键 |
| study_date | 本地日期，唯一 |
| status | ready / in_progress / completed |
| generated_at | ISO 时间 |
| submitted_at | ISO 时间，可空 |
| score | 0–10，可空 |

### `questions`

| 字段 | 说明 |
|---|---|
| id, session_id | 主键、外键 |
| position | 1–10 |
| kind | mcq / fill |
| prompt | 纯法语题干 |
| options_json | 选择题选项；填空题为空 |
| answer | 标准答案 |
| accepted_json | 可接受答案（处理缩写/大小写） |
| option_explanations_json | 每个选项中法解释 |
| explanation_fr / explanation_zh | 题目解释 |
| grammar_key | 语法点键 |
| content_hash | 去重指纹，全局唯一 |

### `responses`

每题每个 session 一条；保存用户答案、正误、批改时间。

### `vocabulary`

每日 10 条；保存类别、词、词性、释义、法语例句、中文例句、来源及 URL。

### `grammar_points`

语法点说明及例句。错题页通过 `grammar_key` 聚合。

## 5. 内容生成策略

1. 用受控 B1 题型模板生成候选集，覆盖时态、代词、冠词、介词、条件式、连接词和词汇搭配。
2. 按当天日期作为稳定随机种子；同一天在任意机器结果一致。
3. 查询历史 `content_hash`；优先选未出现候选。
4. 候选耗尽时允许“最久未见”轮换，并明确保留间隔排序，而不是随机串题。
5. 选择题与填空题在语法主题上成对，但句子、答案位置和表面文本不同。
6. 所有选择题四个选项均有解释；正确与错误原因都说明。
7. 词汇按 `community=5`、`daily=5` 精确抽取，历史优先去重。

## 6. API

- `GET /api/today`：获取/幂等生成今日内容；未提交时隐藏答案。
- `POST /api/sessions/{id}/submit`：校验 10 个答案、事务批改并返回完整解析。
- `GET /api/history`：每日得分、状态、日期。
- `GET /api/sessions/{id}`：历史详情。
- `GET /api/mistakes`：错题及用户答案，支持复盘。
- `GET /api/grammar`：语法点及错误次数。
- `GET /api/vocabulary`：词汇历史。
- `GET /api/health`：运行与数据库健康状态。

错误统一为：`{"error": {"code": "...", "message": "..."}}`。

## 7. UX 设计

### 信息架构

顶部四个主入口：今日 / 历史 / 错题与语法 / 词汇。

### 今日页

- 顶部显示日期、进度、当前分数状态；
- 题目单列卡片，选择题使用大点击区 radio，填空使用清晰输入框；
- 未完成时显示“还有 N 题”；允许提交已填答案，但空题视为错误并提示确认状态；
- 提交后卡片使用图标 + 文字 + 色彩三重反馈，避免只靠颜色；
- 每道题显示标准答案、用户答案、双语解释和全部选项分析。

### 可访问性与视觉

- 正文 17px，题干 20px，行高至少 1.55；
- 内容最大宽度 920px，适配 MacBook；
- 暖白背景、深蓝主色、绿色正确、砖红错误；
- 键盘可操作，焦点轮廓清晰；
- `prefers-reduced-motion` 下关闭动画；
- 发音按钮带可读标签，语言固定 `fr-FR`。

## 8. 安全与隐私

- 仅监听 loopback；
- API 接受 JSON 且限制请求体大小；
- 参数化 SQL；
- 静态文件路径白名单，禁止目录穿越；
- 不收集身份、遥测或外发学习数据；
- 数据库位于项目 `data/`，并被 Git 忽略。

## 9. 测试与验收

### 单元测试

- 每日生成恰好 5 MCQ + 5 fill；
- 题干/选项不含中文；
- 每个 MCQ 四个选项均有解释；
- 同日幂等、跨日去重；
- 词汇 5+5；
- 答案标准化与批改正确；
- 提交后统计、错题与语法聚合正确。

### 集成测试

- 启动临时 HTTP 服务；
- 健康检查、今日内容、提交、历史端点；
- 未提交响应不得泄露答案；
- 非法路由/请求返回结构化错误。

### 浏览器验收

- 实际打开首页；
- 完成一套题并提交；
- 查看解释、历史、错题、语法与词汇；
- 验证控制台无错误、布局无明显溢出。

## 10. 版本计划

- `v0.1`：设计、仓库骨架、核心数据库。
- `v0.2`：每日生成、批改、历史查询。
- `v0.3`：完整 UI、发音、错题/语法。
- `v0.4`：07:00 调度、安装脚本、验收与文档。

每个版本都以测试通过的 Git 检查点提交，主分支保持可运行。
